# Changelog

## 1.1.0 – 2026-10-08

- Spanish interface, in-script guide and documentation (overview and manual).
- The language menu now offers English, Italiano, Français, Deutsch and Español.

## 1.0.0 – 2026-10-08

First public release.

- Link an Illustrator document to a data file: Illustrator Variable Library XML, CSV or tab-delimited TXT (format of Illustrator data merge and VariableImporter).
- Comparison view with status, current text, text in the file and exact change.
- Word-level updates that keep the formatting of unchanged text; optional preservation of manual spaces and line breaks.
- Options to ignore differences in spaces/line breaks and in upper/lower case.
- Update one, selected or all variables; undo of the last update.
- Linked file and per-variable update history stored in the `.ai` file (XMP).
- Binding tools: searchable lists, pick on artboard, bind selection, new variable from text.
- Auto-match of objects whose text equals a variable's value.
- Several objects per variable and bindings that survive copy and paste, through `VAR:name` in the object's Note.
- Interface and manuals in English, Italian, French and German.
